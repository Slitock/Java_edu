# Отчёт по практической работе №1

**Тема:** типы данных, арифметические операции, условные операторы и первые классы

**Проект:** `seminars/sem1`

**Среда выполнения:** OpenJDK 25.0.4.1, Linux

## 1. Цель работы

Освоить базовый синтаксис Java: примитивные типы, арифметику, остаток от
деления, приведение типов, ветвление `if-else`, ввод и вывод, а также
объявление класса, конструкторы и методы доступа к полям.

## 2. Постановка задачи

1. Рассчитать индекс массы тела (BMI) по весу и росту и вывести категорию.
2. Перевести сумму в юанях в рубли по фиксированному курсу.
3. Дополнить конвертер правильным падежом слова «юань» в зависимости от
   последней цифры числа.
4. Создать класс `Car` с полями `model`, `license`, `color`, `year`,
   тремя конструкторами, геттерами, сеттерами и методом `To_String()`.
5. Создать класс `Main`, который создаёт три объекта `Car`, выводит их
   состояние, меняет поля через сеттеры и показывает результат.

## 4. Реализация

### 4.1. Примитивные типы и арифметика

В работе используются два числовых типа:

- `int` — целые значения: сумма в юанях, год выпуска, количество лет;
- `double` — дробные значения: курс, сумма в рублях, рост и вес.

Курс хранится в константе:

```java
final double ROUBLES_PER_YUAN = 11.91;
```

`final` запрещает повторное присваивание: значение фиксируется один раз.
Перевод выполняется умножением:

```java
double roubles = ROUBLES_PER_YUAN * yuan;
```

Если один операнд `double`, результат тоже `double` — это обычное
арифметическое преобразование типов.

### 4.2. Индекс массы тела

Вводное упражнение из PDF использует формулу

$$
BMI = \frac{weight}{(height / 100)^2}
$$

Рост задаётся в сантиметрах, поэтому перед возведением в квадрат делится на
100. Категории выбираются через `if-else`:

| BMI | Категория |
|---|---|
| меньше 18.5 | недостаточный вес |
| от 18.5 до 25 | норма |
| от 25 до 30 | избыточный вес |
| 30 и больше | ожирение |

Расчёт оформлен классом `bmi/src/Bmi.java`: вес и рост читаются через
`Scanner`, BMI выводится с двумя знаками после запятой, категория выбирается
цепочкой `if-else`. Проверены значения 16.33, 22.86, 27.76 и 32.65 — все
четыре ветви достигаются.

### 4.3. Базовый конвертер

```java
Scanner input = new Scanner(System.in);

System.out.print("Введите сумму в юанях: ");
int yuan = input.nextInt();

double roubles = ROUBLES_PER_YUAN * yuan;

System.out.printf("%d CNY = %.2f RUB%n", yuan, roubles);
```

`Scanner` читает целое число, `printf` форматирует вывод: `%d` — целое,
`%.2f` — дробное с двумя знаками после запятой, `%n` — перевод строки.

### 4.4. Конвертер с падежом

Падеж зависит от последней цифры и от чисел 11–14, которые являются
исключением:

```java
int lastDigit = Math.abs(yuan) % 10;
int lastTwoDigits = Math.abs(yuan) % 100;

if (lastTwoDigits >= 11 && lastTwoDigits <= 14) {
    suffix = "китайских юаней";
} else if (lastDigit == 1) {
    suffix = "китайский юань";
} else if (lastDigit >= 2 && lastDigit <= 4) {
    suffix = "китайских юаня";
} else {
    suffix = "китайских юаней";
}
```

`%` возвращает остаток от деления. `Math.abs` нужен, чтобы правило работало
и для отрицательных сумм. Проверка 11–14 идёт первой: иначе число 111
попало бы в ветку «1 → юань».

### 4.5. Класс `Car`

Поля класса:

```java
public class Car {
    private String model;
    private String license;
    private String color;
    private int year;

    private static final int CURRENT_YEAR = 2026;
```

`private` закрывает поля от прямого доступа снаружи. `static` означает, что
`CURRENT_YEAR` принадлежит классу, а не объекту: все автомобили используют
одно значение. `final` запрещает его менять.

Три конструктора:

```java
public Car() {
    this.model = "Не указано";
    this.license = "Транзит";
    this.color = "Не указано";
    this.year = CURRENT_YEAR;
}

public Car(String model, String license, String color, int year) { ... }

public Car(String model, String color) {
    this(model, "Транзит", color, CURRENT_YEAR);
}
```

Третий конструктор вызывает второй через `this(...)`, чтобы не дублировать
присваивания. Это частый приём: один конструктор выполняет основную работу,
остальные передают ему значения по умолчанию.

Метод возраста:

```java
public int getAge() {
    return CURRENT_YEAR - this.year;
}
```

Метод `To_String()` печатает состояние объекта. Имя записано так по
требованию задания; это не переопределение `Object.toString()`, а обычный
метод с нестандартным именем:

```java
public void To_String() {
    System.out.printf("Model: %s| License: %s| Color: %s| Year: %d| Age: %d%n",
            model, license, color, year, getAge());
}
```

### 4.6. Класс `Main`

Создаются три объекта: с конструктором по умолчанию, с полным набором
аргументов и с двумя аргументами. Затем поля меняются через сеттеры:

```java
carDefault.setModel("Moskuich");
carDefault.setColor("Green");
carDefault.setYear(1066);
```

Прямое присваивание `carDefault.model = ...` невозможно, потому что поле
`private`.

### 5.1. Конвертер

```
Введите сумму в юанях: 5
5 CNY = 59.55 RUB
```

```
Введите сумму в китайских юанях: 21
21 китайский юань = 250.11 российских рублей
```

```
Введите сумму в китайских юанях: 111
111 китайских юаней = 1322.01 российских рублей
```

Во втором и третьем запусках видно работу правила для чисел 11–14: 21
получает «юань», а 111 — «юаней».

### 5.2. Класс `Car`

```
---Проверка To_String()---
Model: Не указано| License: Транзит| Color: Не указано| Year: 2026| Age: 0
Model: Lada| License: Транзит| Color: Brown| Year: 2026| Age: 0
Model: BMW| License: C123OC| Color: Pink| Year: 2021| Age: 5
---Изменение полей сеттером ---
Обновленные данные:
  Model: Moskuich
  Color: Green
  Age: 960
```

Возраст 960 получается потому, что в тесте год выставлен в 1066. Это
демонстрация того, что сеттер не проверяет диапазон: при необходимости
проверку нужно добавлять вручную.

## 6. Выводы

- Примитивы `int` и `double` различаются точностью и диапазоном; выбор типа
  влияет на результат деления и формат вывода.
- Остаток `%` позволяет решать задачи на последнюю цифру и кратность.
- `if-else` с цепочкой условий требует правильного порядка проверок:
  исключения вроде 11–14 должны идти раньше общих правил.
- `private` поля и публичные методы реализуют инкапсуляцию: состояние
  меняется только через контролируемые точки.
- Конструкторы можно связывать через `this(...)`, чтобы не повторять код.
- `static final` подходит для констант, общих для всех объектов класса.
